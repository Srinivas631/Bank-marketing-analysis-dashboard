# Bank Marketing Campaign Analysis Dashboard

##  Project Overview

This project analyzes bank marketing campaign data to identify factors influencing customer conversion and campaign effectiveness.

##  Tools Used

* Power BI
* Excel / CSV Dataset

##  Key Insights

* Students have the highest conversion rate (~28%)
* Conversion peaks during specific months (seasonal trends)
* Middle-aged customers (30–50) perform better in banking campaigns
* Most conversions occur within the first 1–5 contact attempts, indicating diminishing returns from repeated outreach.
* Customers contacted 1–2 times have the highest conversion rates.

##  Business Recommendations

* Target high-conversion segments like students and retired customers
* Optimize number of contact attempts
* Focus campaigns during high-performing months
* Prioritize High-Value Customers
* Increasing contact attempts beyond a limit reduces efficiency
